# ICA13 · Bouncing balls

Complete MDN's [Object building practice](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/Objects/Object_building_practice). Save the page as `ica13.html` and submit a link to the live page.

`ica13.html` is HTML5 boilerplate with one `<canvas>` element, a link to `style.css`, and `main.js` loaded with `defer`. The stylesheet is empty. `main.js` is comments only: there is no ball class and no animation loop.

Live link to submit after this folder is on `main`:

`https://dnagubadi.github.io/Senior_Projects/ica/ica13/ica13.html`

## Checklist

- [ ] Make the canvas fill the window and get a 2D drawing context.
- [ ] Define a `Ball` class with position, velocity, color, and size.
- [ ] Add `draw()` and test it with one ball.
- [ ] Add `update()` so a ball bounces off the edges.
- [ ] Loop to create about 25 random balls.
- [ ] Run an animation loop with `requestAnimationFrame` and a translucent fill.
- [ ] Add `collisionDetect()` last.
- [ ] Push it live and open the link above to confirm it is the page you submit.
