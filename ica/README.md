# In-class assignments

Starter folders for ICA11, ICA12, and ICA13. Each page is a shell: markup, a stylesheet link, and a script file that contains only TODO comments. The solutions are not in this folder. Write them yourself, then push and submit the live GitHub Pages link.

After these files are on `main`, the pages are served from [https://dnagubadi.github.io/Senior_Projects/](https://dnagubadi.github.io/Senior_Projects/).

| Assignment | Page | Submit this link once it is on `main` |
| --- | --- | --- |
| [ICA11 · A Silly Story](ica11/) | [ica11.html](ica11/ica11.html) | `https://dnagubadi.github.io/Senior_Projects/ica/ica11/ica11.html` |
| [ICA12 · Quote / API](ica12/) | [ica12.html](ica12/ica12.html) | `https://dnagubadi.github.io/Senior_Projects/ica/ica12/ica12.html` |
| [ICA13 · Bouncing balls](ica13/) | [ica13.html](ica13/ica13.html) | `https://dnagubadi.github.io/Senior_Projects/ica/ica13/ica13.html` |

Preview locally from the repo root:

```bash
python3 -m http.server 8080
```

Then open:

- `http://localhost:8080/ica/ica11/ica11.html`
- `http://localhost:8080/ica/ica12/ica12.html`
- `http://localhost:8080/ica/ica13/ica13.html`
