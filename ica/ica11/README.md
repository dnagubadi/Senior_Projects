# ICA11 · A Silly Story

Complete MDN's [Silly story generator](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/First_steps/Silly_story_generator). Change the CSS for every element, rewrite the story so it is your own and stays PG-13, and submit a link to the live page named `ica11.html`.

`ica11.html` is HTML5 boilerplate plus the starter structure from that MDN page: custom-name field, US/UK locale radios, generate button, and an empty story paragraph. MDN's JavaScript is not included. `style.css` is empty. `main.js` is comments only.

Live link to submit after this folder is on `main`:

`https://dnagubadi.github.io/Senior_Projects/ica/ica11/ica11.html`

## Checklist

- [ ] Read the MDN page and keep the starter HTML in `ica11.html`.
- [ ] Write a helper that picks a random item from an array.
- [ ] Create three word arrays.
- [ ] Add a click handler that fills a story template.
- [ ] Use the custom-name input in the story.
- [ ] Use the UK/US toggle to convert weight and temperature.
- [ ] Write your own PG-13 story and word lists.
- [ ] Restyle every element in `style.css`.
- [ ] Test the page.
- [ ] Push it live and open the link above to confirm it is the page you submit.
